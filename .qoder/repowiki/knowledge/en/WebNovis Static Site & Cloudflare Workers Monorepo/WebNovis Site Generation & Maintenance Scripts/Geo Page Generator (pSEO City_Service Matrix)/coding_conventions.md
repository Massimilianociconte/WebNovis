- Each page type is generated by a dedicated `render-<type>.js` module exporting a single `generate*Page` function that returns raw HTML or null on failure, keeping the main loop uniform across agenzia, realizzazione, servizio, and hubs.
- Renderers follow a fixed pipeline: load Rho base template via `paths-core.getBasePage`, resolve SEO copy through `editorial.applyEditorialSeoOverrides`, render content with `njkEnv.render('<type>-content.njk', ctx)`, inject head/meta via `head-meta.updateDerivedHeadMeta`, append JSON-LD from `schema.generateSchemas`, validate with `validate.validatePage`, then finalize and write through `paths.finalizePublishedHtml`.
- Indexability is driven by tier classification from `config.resolvePageTier` applied to the canonical path, gating both template behavior and whether a page is included in nearest-city/linking sets via `isIndexableGeoPath`.
- Per-city personalization uses a consistent lookup pattern: read `data/content-blocks/tier1-<city>-<page>.json` when tier === 1 and pass it as `tier1Content` into the Nunjucks context, falling back to AI blocks from `contentBlocks.get(city.slug)` otherwise.
- Validation issues use a severity prefix convention: `⛔ CRITICAL` or `⛔ UNSUPPORTED CLAIM` block generation (increment `blockedOrFailed`), while `⚠ WARNING` records do not stop the pipeline.
- Shared constants (SITE, PAGE_DATE tokens, PUBLISH_DIR, REPORT_DIR, CLI flags) are centralized in `config.js` and re-exported to all renderers rather than being passed as arguments, keeping generators stateless.
