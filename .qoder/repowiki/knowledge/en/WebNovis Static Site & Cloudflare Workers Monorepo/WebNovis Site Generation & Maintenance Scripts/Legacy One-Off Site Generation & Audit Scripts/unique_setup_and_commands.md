Scripts are run directly: `node scripts/legacy/generate-city-pages.js`, `node scripts/legacy/gen-geo-pages.js`, or `python scripts/legacy/root-oneoff/<script>.py`. Many root-oneoff scripts still contain absolute Windows paths (e.g. `C:\Users\...`) and are no longer executable as-is; they are kept purely for historical reference since the `scripts/` directory is excluded from the public build via `.assetsignore` and `scripts/prepare-public-artifact.js`.
