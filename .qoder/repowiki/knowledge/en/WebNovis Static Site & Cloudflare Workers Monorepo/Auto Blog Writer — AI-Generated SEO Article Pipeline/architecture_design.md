Single-file orchestrator (`blog/auto-writer.js`) that drives a four-stage pipeline: (1) topic selection from `topics-queue.json` (entries marked `used: true` after generation); (2) prompt assembly via `buildMasterPrompt`, which injects brand rules, required article structure (A→H sections), keyword coverage, internal linking constraints, and E-E-A-T signals into a large static Italian prompt; (3) AI generation through `generateWithAI`, which tries Google Gemini (`gemini-2.5-flash` via `generativelanguage.googleapis.com`) first, falls back to Groq (`llama-3.3-70b-versatile` via OpenAI-compatible `/chat/completions`), with retry and JSON repair (`repairJSON` strips control chars, trailing commas, unescaped newlines, then regex-extracts `{...}`); (4) output rendering via shared helpers from `./build-articles.js` (`buildArticleHTML`, `buildRelatedArticlesHTML`) plus `../config/seo-html-transforms.normalizeHtmlDocumentStructure`, writing each article as `<slug>.html` under `BLOG_DIR`, appending metadata to `articles-log.json`, marking topics used, regenerating `blog/index.html` (preserving per-article custom images via `extractCustomImageMap`), spawning `generate-sitemap.js` via `child_process.execFileSync`, and finally calling `../indexnow-submit.submitNewArticles`. CLI modes: default batch generation, `--dry-run` (no writes), `--count N`, `--rebuild-index` (skip generation, rebuild index + sitemap). Dependency direction is one-way: this module depends on `build-articles`, `config/seo-html-transforms`, and `indexnow-submit`; nothing in those modules depends back on the writer.
