The module is a flat collection of browser-side assets split into two directories: `css/` holds theme and feature stylesheets (e.g. `style.css`, `revolution.css`, `search.css`, `social-feed-modern.css`, `portfolio-premium.css`) alongside their minified `.min.css` counterparts; `js/` holds runtime scripts including the main interaction bundle (`main.js`), a lightweight site configuration object (`site-config.js` exposing `window.WEBNOVIS_SITE_CONFIG` for Turnstile/form settings), a chat UI shell injector (`weby-shell.js` that builds the Weby AI chat DOM on demand), feature-specific modules (`chat.js`, `cursor.js`, `globe.js`, `text-effects.js`, `web-vitals-reporter.js`, `footer-widgets-loader.js`, `noncritical-loader.js`, `designrush-loader.js`, `search.js`), each with a corresponding `.min.js` build artifact. Dependency direction is one-way: feature scripts consume the shared config from `site-config.js` and are loaded by the page template; there is no module system — files rely on global scope and DOM APIs directly. Minified variants are kept in sync with source files, indicating an external build step produces both versions.
