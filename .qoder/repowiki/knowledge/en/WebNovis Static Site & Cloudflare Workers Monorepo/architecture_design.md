The repository is organized as a flat collection of generated HTML pages (one per city/service combination) plus shared build tooling. The Node.js `build.js` pipeline minifies JS (Terser) and CSS (LightningCSS with CleanCSS fallback), discovers assets referenced by HTML, and applies SEO transforms to `src/html/` templates. Geo-targeted pages are produced by scripts under `scripts/` driven by JSON data in `content_data/`, while the `blog/` module generates AI-written articles. Runtime serverless logic lives in `workers/` (AI chat and form proxy) configured via per-worker `wrangler.jsonc`. All outputs land in `dist/`, which Wrangler publishes as a Cloudflare Pages asset site (`html_handling: none` preserves `.html` URLs). Top-level `package.json` scripts orchestrate the full pipeline: `npm run build:geo` generates pages, `npm run build` compiles assets, `npm run build:search-index` builds search indexes, and `npm run deploy:site` runs the complete dist build then `wrangler deploy`. Tests under `tests/` cover regression, SEO governance, and worker endpoints.
