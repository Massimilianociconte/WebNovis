The project is a Node.js-driven static-site generator with Express as the dev server (`server.js`) and a comprehensive `package.json` script surface driving every build step. Core layers: (1) `config/` centralizes cross-cutting concerns — `security-headers.js` defines CSP, CORS origins, HSTS, and emits Netlify/Cloudflare `_headers` via `buildStaticHeadersFile()`; `entity-facts.js` normalizes JSON-LD by canonicalizing WebNovis entities, stripping forbidden `sameAs` URLs, and rewriting LocalBusiness/Organization IDs. (2) `src/html/` holds hand-authored page templates (e.g. `servizi/index.html`) with embedded inline styles, OG/Twitter meta, schema.org `<script type="application/ld+json">`, and prerender/prefetch `speculationrules`. (3) `scripts/` contains the build toolchain: `build.js` compiles assets, `generate-sitemap.js` produces sitemaps, `generate-all-geo.js` expands city/zone pages, `normalize-public-html.js` post-processes output HTML, `update-footer.js` injects shared footers, and `prepare-public-artifact.js` bundles everything into a `dist/` artifact. (4) `workers/` hosts two Cloudflare Workers (`webnovis-ai` for the chatbot, `webnovis-forms` for contact submissions), each with its own `wrangler.jsonc` and deployed via `npm run ai:deploy` / `forms:deploy`. (5) `tests/` provides regression suites covering SEO, security headers, HTML structure, entity claims, LCP hero, and build pipeline correctness, orchestrated through `test:regressions`. Dependency direction flows one-way: scripts read source HTML/CSS/JS, transform them, and emit a deployable `dist/` artifact verified by `verify-public-artifact.js`; nothing in `src/html` imports build code.
