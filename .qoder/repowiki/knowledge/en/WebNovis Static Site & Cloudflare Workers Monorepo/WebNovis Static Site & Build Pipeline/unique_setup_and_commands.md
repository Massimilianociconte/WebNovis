Build pipeline is driven entirely by npm scripts: `npm run build` compiles assets, `npm run build:site:dist` produces the final `dist/` artifact, `npm run sync:headers` regenerates `_headers` from `config/security-headers.js`, `npm run build:geo` expands city/zone pages, `npm run normalize:public-html` post-processes generated HTML, `npm run validate:pages` runs page-level validation, and `npm run test:regressions` executes the full regression suite. Deployment uses `npm run deploy:site` (Wrangler dry-run then publish) and separate workers via `npm run ai:deploy` / `forms:deploy` with per-worker `wrangler.jsonc` configs.
