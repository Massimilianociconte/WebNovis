Each worker is deployed via `wrangler deploy` using its own `wrangler.jsonc`. Secrets are managed through Wrangler (e.g. `wrangler secret put TURNSTILE_SECRET`, `GEMINI_API_KEY_CHAT`, `GEMINI_API_KEY_SEARCH`, `BREVO_API_KEY`) — they must not be committed. The `webnovis-ai` worker requires a KV namespace bound to the `SESSIONS` binding (auto-provisioned on first deploy if `id` omitted). Development variables can be copied from `.dev.vars.example`.
