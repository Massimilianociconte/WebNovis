Two sub-trees with distinct purposes. `scripts/legacy/*.js` are standalone Node generators (e.g. `generate-city-pages.js`, `gen-geo-pages.js`, `gen-accessibilita.js`, `gen-pillar-articles.js`) that read a single Rho template HTML file from the repo root, apply regex-based text/image replacements driven by an in-file `cities` array, and write per-city output pages; they depend only on Node's built-in `fs` and `path`. `scripts/legacy/root-oneoff/` holds dozens of throwaway scripts (`check*.js|py`, `fix*.js|py`, `convert*.js|py`, `update*.py`, `deep_audit.py`, etc.) that were originally committed at the repository root and thus publicly served via GitHub Pages — they perform image audits, WebP conversion, path fixing, form inspection, JSON-LD updates, and content extraction using plain `fs`/`os`/`re`/`BeautifulSoup`-style parsing without any package manager. There is no shared library or CLI framework inside this module; each script is self-contained and invoked directly via `node <file>` or `python <file>`. The top-level `README.md` documents which legacy scripts have been superseded by `scripts/generate-all-geo.js` and `blog/auto-writer.js`, establishing the deprecation boundary.
