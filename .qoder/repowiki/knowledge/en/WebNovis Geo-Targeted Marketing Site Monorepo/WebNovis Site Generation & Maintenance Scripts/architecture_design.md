The `scripts/` directory is organized as a flat CLI toolbox plus a structured sub-pipeline: `geo/main.js` orchestrates the unified pSEO generator by composing modules for config, data, templating (`render-agenzia`, `render-realizzazione`, `render-servizio`, `render-hubs`), schema injection, validation, and publishing; all child scripts share the same runtime contract (Node.js CLI invoked via `node <script>` or `npm run build:*`) and write output into the site's published HTML tree. The `legacy/` folder holds deprecated one-off scripts (both `.js` and `.py`) that performed the same tasks before being consolidated into `generate-all-geo.js`; they are kept only as historical reference per the README deprecation notice. Top-level scripts in `scripts/` are independent maintenance helpers (audit, fix, migrate, SEO enrichment) that operate directly on the built site files without depending on each other.
