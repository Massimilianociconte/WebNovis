Each source file ships a paired `.min.*` artifact (e.g. `main.js` ↔ `main.min.js`, `style.css` ↔ `style.min.css`) generated by an external minifier run during build; before deployment `site-config.js` must be edited to set `TURNSTILE_SITEKEY`, `FORM_SUBMIT_MODE` (`web3forms` or `proxy`), `FORM_PROXY_URL`, and `TURNSTILE_THEME` to enable CAPTCHA and form routing.
