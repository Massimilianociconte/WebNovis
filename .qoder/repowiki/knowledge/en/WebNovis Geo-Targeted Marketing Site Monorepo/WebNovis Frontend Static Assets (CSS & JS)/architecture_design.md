Flat asset bundle split into two sibling directories consumed directly by page templates with no module system or bundler.

- `css/` contains the design-system stylesheet (`style.css`, ~8k lines defining CSS custom properties, color tokens, typography, cookie banner, marquee, and critical FOUC-prevention rules) plus feature/theme sheets (`revolution.css`, `search.css`, `social-feed-modern.css`, `portfolio-premium.css`, `nicole-inspired.css`, `leviathan-inspired.css`, `weby-mobile-fix.css`) — each shipped alongside a minified `.min.css` counterpart produced by an external build step.
- `js/` is organized as independent IIFE / top-level scripts that attach behavior to existing DOM nodes: `site-config.js` exposes the shared runtime config object `window.WEBNOVIS_SITE_CONFIG`; `main.js` is the monolithic interaction bundle handling mobile nav, scroll reveal, IntersectionObserver-based animations, particle canvas, magnetic/3D tilt cards, parallax, social feed auto-scroll, counters, testimonials carousel, newsletter subscription, and Cloudflare Turnstile form integration; `weby-shell.js` injects the Weby AI chat aside markup on demand; `chat.js` implements the full chat UI, session persistence, keep-alive health checks, lead-intent detection, and message streaming against a remote Worker API; `search.js` provides Fuse.js fuzzy local search with optional remote AI enrichment via `/api/search-ai`; `cursor.js`, `globe.js`, `text-effects.js`, `footer-widgets-loader.js`, `noncritical-loader.js`, `designrush-loader.js`, `web-vitals-reporter.js` are self-contained feature modules loaded only when needed. Dependency direction is one-way: feature scripts read from `window.WEBNOVIS_SITE_CONFIG` and never import each other; they are wired into pages by template scripts that decide which files to load based on route and device capability.
