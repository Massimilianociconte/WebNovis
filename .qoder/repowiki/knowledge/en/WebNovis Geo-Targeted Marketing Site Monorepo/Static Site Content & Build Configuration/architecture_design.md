Two-layer layout under this scope: `src/html/` holds the hand-written static page templates (root pages plus a `servizi/` subdirectory of service landing pages) with fully inline `<head>` metadata — OG/Twitter tags, canonical links, `speculationrules` for prerender/prefetch, and `application/ld+json` blocks. `config/` is a flat collection of Node.js modules consumed by the build pipeline (`scripts/`) to transform and validate those pages at build time. Key modules include `entity-facts.js`, which centralizes WebNovis organization/local business identity and provides `normalizeEntityJsonLd()` to rewrite any inlined JSON-LD to canonical IDs and strip forbidden `sameAs` URLs; `security-headers.js`, which defines CSP directives, HSTS, CORS origins, and emits platform `_headers` files via `buildStaticHeadersFile()`; and supporting configs (`blog-cluster-links.js`, `content-claim-governance.js`, `geo-editorial.js`, `image-policy.js`, `priority-snippets.js`, `pseo-governance.js`, `publish-targets.js`, `seo-html-transforms.js`, `site-footer.js`, `build-date.js`) that feed into sitemap generation, geo-page expansion, footer injection, and post-processing steps. Dependency direction is one-way: build scripts read these config modules and the raw HTML, then emit a `dist/` artifact — source HTML never imports build code.
