- Cross-cutting build concerns live in `config/*.js` modules that export both frozen data constants (e.g. `ENTITY_FACTS`, `SECURITY_HEADERS`) and transformation functions (e.g. `normalizeEntityJsonLd`, `buildCspWithNonce`, `buildStaticHeadersFile`) instead of scattering values across build scripts.
- Each HTML page embeds all SEO metadata inline — OG/Twitter meta, canonical links, `speculationrules` for prerender/prefetch, and `application/ld+json` blocks — so the build pipeline can validate and normalize them without a server-side template engine.
- JSON-LD entities are normalized centrally: `entity-facts.js` rewrites any WebNovis-related `@id` to canonical organization/local business IDs and strips forbidden `sameAs` entries during the build pass.
- Security headers and cache rules are authored once in `config/security-headers.js` and regenerated into platform-specific `_headers` formats via `sync:headers`, keeping runtime and static header definitions in sync.
- Pages follow a consistent structure with a skip-link anchor, semantic `<nav>`/`<main>`/`<footer>` sections, and inline CSS scoped to page-specific components, while shared styles are loaded from minified assets under `/css/`.
