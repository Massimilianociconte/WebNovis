External chatbot widget integrated via CSS/JS assets (`weby-mobile-fix.css`, `chat.js`). The README lists it as a built-in feature ('Chatbot Weby per assistenza immediata'). It loads independently of the consent-gated analytics flow and is treated as a core UI component rather than optional tracking.
